Replace this file with your real trading ebooks — each book is just a self-hosted HTML file in this ebooks/ folder, opened full-screen inside the site when a reader taps its cover on the Ebook Library panel.

How to add a real ebook

1. Drop your book's HTML file in ebooks/ (e.g. ebooks/price-action-101.html).

2. Add an entry for it in data/ebooks.json:

{
  "id": "price-action-101",
  "title": "Price Action 101",
  "author": "Your Name",
  "file": "ebooks/price-action-101.html"
}

3. Remove this demo entry once you have real books.

Cover

Covers on the shelf are auto-generated from the title (no image needed) — a future version can add a "cover" image field if you want real cover art.
